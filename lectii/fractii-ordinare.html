Sari la conținut

O fracție arată câte părți egale luăm dintr-un întreg. Se scrie cu două numere naturale și o linie de fracție:

$$\frac{a}{b}, \quad b \neq 0$$

  • $a$ este numărătorul: câte părți luăm;
  • $b$ este numitorul: în câte părți egale împărțim întregul.

Exemplu

O pizza este tăiată în 8 felii egale. Mănânci 3 felii. Ai mâncat $\frac{3}{8}$ din pizza.

Tipuri de fracții

  • Subunitară, dacă $a < b$. Exemplu: $\frac{2}{5}$. Este mai mică decât 1.
  • Echiunitară, dacă $a = b$. Exemplu: $\frac{7}{7} = 1$.
  • Supraunitară, dacă $a > b$. Exemplu: $\frac{9}{4}$. Este mai mare decât 1.

Reține

Dintre două fracții cu același numitor, este mai mare fracția care are numărătorul mai mare. De exemplu, $\frac{5}{9} > \frac{2}{9}$.

Exerciții

  1. Scrie fracția: patru părți din zece părți egale.

    Vezi rezolvarea

    $\frac{4}{10}$

  2. Spune ce fel de fracții sunt: $\frac{3}{11}$, $\frac{12}{12}$, $\frac{15}{6}$.

    Vezi rezolvarea

    $\frac{3}{11}$ este subunitară ($3 < 11$), $\frac{12}{12}$ este echiunitară, iar $\frac{15}{6}$ este supraunitară ($15 > 6$).

  3. Ordonează crescător: $\frac{7}{12}$, $\frac{1}{12}$, $\frac{11}{12}$, $\frac{5}{12}$.

    Vezi rezolvarea

    Numitorii sunt egali, deci comparăm numărătorii: $\frac{1}{12} < \frac{5}{12} < \frac{7}{12} < \frac{11}{12}$.

A fraction shows how many equal parts we take from a whole. We write it with two whole numbers and a fraction bar:

$$\frac{a}{b}, \quad b \neq 0$$

  • $a$ is the numerator: how many parts we take;
  • $b$ is the denominator: into how many equal parts we cut the whole.

Example

A pizza is cut into 8 equal slices. You eat 3 slices. You ate $\frac{3}{8}$ of the pizza.

Types of fractions

  • Proper fraction, if $a < b$. Example: $\frac{2}{5}$. It is less than 1.
  • Equal to one, if $a = b$. Example: $\frac{7}{7} = 1$.
  • Improper fraction, if $a > b$. Example: $\frac{9}{4}$. It is greater than 1.

Remember

When two fractions have the same denominator, the one with the bigger numerator is bigger. For example, $\frac{5}{9} > \frac{2}{9}$.

Exercises

  1. Write the fraction: four parts out of ten equal parts.

    Show solution

    $\frac{4}{10}$

  2. What type is each fraction: $\frac{3}{11}$, $\frac{12}{12}$, $\frac{15}{6}$?

    Show solution

    $\frac{3}{11}$ is proper ($3 < 11$), $\frac{12}{12}$ is equal to one, and $\frac{15}{6}$ is improper ($15 > 6$).

  3. Put in increasing order: $\frac{7}{12}$, $\frac{1}{12}$, $\frac{11}{12}$, $\frac{5}{12}$.

    Show solution

    The denominators are equal, so we compare the numerators: $\frac{1}{12} < \frac{5}{12} < \frac{7}{12} < \frac{11}{12}$.
