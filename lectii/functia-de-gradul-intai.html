Sari la conținut

O funcție $f : \mathbb{R} \to \mathbb{R}$ de forma

$$f(x) = ax + b, \quad a \neq 0$$

cu $a, b \in \mathbb{R}$, se numește funcție de gradul I. Numărul $a$ este coeficientul lui $x$ (panta dreptei), iar $b$ este termenul liber.

Graficul

Graficul funcției de gradul I este o dreaptă. Ca să o desenăm, ne ajung două puncte. De obicei folosim punctele de intersecție cu axele:

  • cu axa $Ox$: rezolvăm $f(x) = 0$ și obținem $x = -\frac{b}{a}$, deci punctul $A\left(-\frac{b}{a}, 0\right)$;
  • cu axa $Oy$: calculăm $f(0) = b$, deci punctul $B(0, b)$.

Exemplu

Fie $f(x) = 2x - 4$. Din $2x - 4 = 0$ obținem $x = 2$, deci $A(2, 0)$. Apoi $f(0) = -4$, deci $B(0, -4)$.

Monotonia

  • dacă $a > 0$, funcția este strict crescătoare;
  • dacă $a < 0$, funcția este strict descrescătoare.

Pentru $f(x) = 2x - 4$ avem $a = 2 > 0$, deci funcția este strict crescătoare.

Semnul funcției

Funcția se anulează în $x_0 = -\frac{b}{a}$. La dreapta lui $x_0$, $f(x)$ are semnul lui $a$. La stânga lui $x_0$, $f(x)$ are semn contrar lui $a$.

Pentru $f(x) = 2x - 4$: $f(x) < 0$ pentru $x < 2$ și $f(x) > 0$ pentru $x > 2$.

Exerciții

  1. Pentru $f(x) = -3x + 6$, află punctele de intersecție ale graficului cu axele și monotonia funcției.

    Vezi rezolvarea

    $-3x + 6 = 0 \Rightarrow x = 2$, deci $A(2, 0)$. $f(0) = 6$, deci $B(0, 6)$. Pentru că $a = -3 < 0$, funcția este strict descrescătoare.

  2. Află $a$ astfel încât punctul $M(2, 7)$ să aparțină graficului funcției $f(x) = ax + 1$.

    Vezi rezolvarea

    $f(2) = 7 \Rightarrow 2a + 1 = 7 \Rightarrow a = 3$.

  3. Stabilește semnul funcției $f(x) = x - 5$.

    Vezi rezolvarea

    Funcția se anulează în $x_0 = 5$ și $a = 1 > 0$. Deci $f(x) < 0$ pentru $x < 5$ și $f(x) > 0$ pentru $x > 5$.

A function $f : \mathbb{R} \to \mathbb{R}$ of the form

$$f(x) = ax + b, \quad a \neq 0$$

with $a, b \in \mathbb{R}$, is called a linear function (a function of degree one). The number $a$ is the coefficient of $x$ (the slope of the line), and $b$ is the constant term.

The graph

The graph of a linear function is a straight line. To draw it, two points are enough. We usually use the points where the line meets the axes:

  • the $x$-axis: solve $f(x) = 0$ and get $x = -\frac{b}{a}$, so the point is $A\left(-\frac{b}{a}, 0\right)$;
  • the $y$-axis: calculate $f(0) = b$, so the point is $B(0, b)$.

Example

Let $f(x) = 2x - 4$. From $2x - 4 = 0$ we get $x = 2$, so $A(2, 0)$. Then $f(0) = -4$, so $B(0, -4)$.

Increasing or decreasing

  • if $a > 0$, the function is strictly increasing;
  • if $a < 0$, the function is strictly decreasing.

For $f(x) = 2x - 4$ we have $a = 2 > 0$, so the function is strictly increasing.

The sign of the function

The function is zero at $x_0 = -\frac{b}{a}$. To the right of $x_0$, $f(x)$ has the same sign as $a$. To the left of $x_0$, it has the opposite sign.

For $f(x) = 2x - 4$: $f(x) < 0$ for $x < 2$ and $f(x) > 0$ for $x > 2$.

Exercises

  1. For $f(x) = -3x + 6$, find where the graph meets the axes and whether the function increases or decreases.

    Show solution

    $-3x + 6 = 0 \Rightarrow x = 2$, so $A(2, 0)$. $f(0) = 6$, so $B(0, 6)$. Because $a = -3 < 0$, the function is strictly decreasing.

  2. Find $a$ so that the point $M(2, 7)$ is on the graph of $f(x) = ax + 1$.

    Show solution

    $f(2) = 7 \Rightarrow 2a + 1 = 7 \Rightarrow a = 3$.

  3. Find the sign of $f(x) = x - 5$.

    Show solution

    The function is zero at $x_0 = 5$ and $a = 1 > 0$. So $f(x) < 0$ for $x < 5$ and $f(x) > 0$ for $x > 5$.
