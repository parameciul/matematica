Fișă de lucru: monotonia șirurilor

Publicat 17 noiembrie 2026 · de Laura Miron

Deschide PDF

Rezumat

Fișa recapitulează pe scurt ce înseamnă un șir crescător, descrescător, monoton sau nemonoton și cele trei metode de studiu al monotoniei: diferența, raportul pentru termeni pozitivi și inducția pentru șiruri date prin recurență, fiecare cu un exemplu rezolvat. Apasă «Verifică» lângă un exercițiu. Răspunsurile rămân pe acest dispozitiv.

La finalul fișei vei ști să:

  • studiezi monotonia unui șir cu diferența $a_{n+1}-a_n$;
  • studiezi monotonia unui șir cu termeni pozitivi cu raportul $\frac{a_{n+1}}{a_n}$;
  • studiezi prin inducție monotonia unui șir dat printr-o relație de recurență;
  • alegi metoda potrivită și arăți că un șir nu este monoton.

1. Șiruri monotone

Definiție

Șirul $(a_n)_{n\ge 1}$ este:

  • strict crescător, dacă $a_n<a_{n+1}$ pentru orice $n\ge 1$;
  • crescător, dacă $a_n\le a_{n+1}$ pentru orice $n\ge 1$;
  • strict descrescător, dacă $a_n>a_{n+1}$ pentru orice $n\ge 1$;
  • descrescător, dacă $a_n\ge a_{n+1}$ pentru orice $n\ge 1$.

Un șir crescător sau descrescător se numește monoton.

Un șir este nemonoton dacă există trei termeni consecutivi care „urcă și apoi coboară” sau „coboară și apoi urcă”, de exemplu $a_1<a_2$ și $a_2>a_3$.

2. Cele trei metode

2.1. Diferența

★ Metodă

Studiem semnul diferenței $a_{n+1}-a_n$

  1. Calculăm $a_{n+1}-a_n$ și o aducem la o formă simplă (aducem la același numitor, dăm factor comun).
  2. Dacă $a_{n+1}-a_n>0$ pentru orice $n$, șirul este strict crescător.
  3. Dacă $a_{n+1}-a_n<0$ pentru orice $n$, șirul este strict descrescător.

Exemplul 1

$a_n=\frac{n+2}{2n+1}$.

$$a_{n+1}-a_n=\frac{n+3}{2n+3}-\frac{n+2}{2n+1}=\frac{(n+3)(2n+1)-(n+2)(2n+3)}{(2n+1)(2n+3)}=\frac{-3}{(2n+1)(2n+3)}<0.$$

Șirul este strict descrescător.

2.2. Raportul

★ Metodă

Comparăm raportul $\frac{a_{n+1}}{a_n}$ cu $1$

  1. Verificăm întâi că toți termenii sunt strict pozitivi. Altfel metoda nu se aplică.
  2. Calculăm $\frac{a_{n+1}}{a_n}$ și îl simplificăm.
  3. Dacă raportul este mai mare decât $1$ pentru orice $n$, șirul este strict crescător; dacă este mai mic decât $1$, șirul este strict descrescător.

Exemplul 2

$a_n=\frac{3^n}{n+1}$, cu toți termenii strict pozitivi.

$$\frac{a_{n+1}}{a_n}=\frac{3^{n+1}}{n+2}\cdot\frac{n+1}{3^n}=\frac{3n+3}{n+2}>1,\ \text{pentru că}\ 3n+3>n+2.$$

Șirul este strict crescător.

2.3. Inducția

★ Metodă

Pentru un șir dat prin $x_1$ și $x_{n+1}=g(x_n)$

  1. Verificăm $x_1<x_2$ (sau $x_1>x_2$).
  2. Arătăm că din $x_k<x_{k+1}$ rezultă $x_{k+1}<x_{k+2}$ (sau inegalitățile inverse).
  3. Uneori demonstrăm întâi prin inducție că termenii stau într-un interval, apoi studiem semnul diferenței $x_{n+1}-x_n$.

Exemplul 3

$x_1=2$ și $x_{n+1}=\frac{x_n+3}{2}$. Arătăm că $x_n<x_{n+1}$ pentru orice $n\ge 1$.

  • Verificare: $x_2=\frac{5}{2}>2=x_1$.
  • Pasul de inducție: din $x_k<x_{k+1}$ rezultă $x_k+3<x_{k+1}+3$, deci $\frac{x_k+3}{2}<\frac{x_{k+1}+3}{2}$, adică $x_{k+1}<x_{k+2}$.

Conform principiului inducției matematice, șirul este strict crescător.

3. Cum aleg metoda?

De reținut

  • Termenul general este o sumă sau o fracție cu $n$ la numărător și la numitor → diferența.
  • Termenul general conține puteri $q^n$ sau produse lungi, iar termenii sunt pozitivi → raportul (se simplifică mult).
  • Am doar relația $x_{n+1}=g(x_n)$ → inducția.

Exerciții

A. Metoda diferenței

  1. Studiați monotonia șirurilor:

    a) $a_n=3n-7$;

    b) $b_n=4-n^2$;

    c) $c_n=\frac{3n-1}{n+1}$.

  2. Diferența și semnul ei.

    a) Arătați că șirul $a_n=\frac{5-2n}{n+3}$, $n\ge 1$, este strict descrescător.

    b) Fie $b_n=n^2-6n+10$, $n\ge 1$. Calculați $b_1$, $b_2$, $b_3$, $b_4$ și $b_{n+1}-b_n$. Este șirul monoton? Începând de la ce rang este strict crescător?

  3. Studiați monotonia șirurilor:

    a) $a_n=1+\frac{1}{2}+\frac{1}{3}+\ldots+\frac{1}{n}$;

    b) $b_n=\frac{1}{n+1}+\frac{1}{n+2}+\ldots+\frac{1}{2n}$.

    Indicație: la b) scrieți atent $b_{n+1}$: ce termeni apar în plus și ce termen dispare?

  4. Fie $a$ un număr real și șirul $a_n=n^2+an$, $n\ge 1$.

    a) Determinați valorile lui $a$ pentru care șirul este strict crescător.

    b) Pentru $a=-3$, este șirul crescător? Este strict crescător?

B. Metoda raportului

  1. Studiați monotonia șirurilor:

    a) $a_n=\frac{n+1}{4^n}$;

    b) $b_n=\frac{3^n}{2n+1}$.

  2. Studiați monotonia șirurilor:

    a) $a_n=\frac{1\cdot 4\cdot 7\cdot\ldots\cdot(3n-2)}{3\cdot 6\cdot 9\cdot\ldots\cdot(3n)}$;

    b) $b_n=\frac{(n+1)(n+2)\cdot\ldots\cdot(2n)}{4^n}$.

  3. Fie șirul $a_n=n\cdot\left(\frac{2}{3}\right)^n$, $n\ge 1$.

    a) Arătați că $\frac{a_{n+1}}{a_n}=\frac{2(n+1)}{3n}$.

    b) Comparați acest raport cu $1$, în funcție de $n$.

    c) Este șirul monoton? Începând de la ce rang este strict descrescător?

  4. Fie șirul $a_n=-\frac{2^n}{n}$, $n\ge 1$. Un elev scrie: „$\frac{a_{n+1}}{a_n}=\frac{2n}{n+1}\ge 1$, deci șirul este crescător.”

    a) Calculați $a_1$, $a_2$, $a_3$. Este corectă concluzia elevului?

    b) Unde greșește elevul? Stabiliți corect monotonia șirului.

C. Metoda inducției

  1. Studiați monotonia șirurilor date prin recurență, pentru $n\ge 1$:

    a) $x_1=1$, $x_{n+1}=\frac{x_n+8}{3}$;

    b) $y_1=10$, $y_{n+1}=\frac{y_n+8}{3}$;

    c) $z_1=4$, $z_{n+1}=\frac{z_n+8}{3}$.

    Ce observați?

  2. Șirul $(x_n)_{n\ge 1}$ are $x_1=9$ și $x_{n+1}=\sqrt{x_n+20}$, pentru $n\ge 1$.

    a) Arătați prin inducție că $x_n>5$ pentru orice $n\ge 1$.

    b) Arătați prin inducție că șirul este strict descrescător.

  3. Șirul $(x_n)_{n\ge 1}$ are $x_1=1$ și $x_{n+1}=\frac{x_n}{1+x_n}$, pentru $n\ge 1$.

    a) Arătați prin inducție că $x_n>0$ pentru orice $n\ge 1$.

    b) Arătați că $x_{n+1}-x_n=-\frac{x_n^2}{1+x_n}$ și dedu monotonia șirului.

    c) Calculați $x_2$, $x_3$, $x_4$, intuiți formula termenului general și demonstrați-o prin inducție.

  4. Șirul $(x_n)_{n\ge 1}$ are $x_1=3$ și $x_{n+1}=3-\frac{2}{x_n}$, pentru $n\ge 1$.

    a) Arătați prin inducție că $x_n>2$ pentru orice $n\ge 1$.

    b) Arătați că $x_{n+1}-x_n=-\frac{(x_n-1)(x_n-2)}{x_n}$ și dedu că șirul este strict descrescător.

D. Alegeți metoda

  1. Studiați monotonia șirurilor:

    a) $a_n=\sqrt{n+1}-\sqrt{n}$;

    b) $b_n=n+\frac{1}{n}$;

    c) $c_n=\frac{n^2}{n^2+1}$.

    Indicație: la a) amplificați cu conjugata.

  2. Precizați care dintre șirurile următoare sunt monotone. Justificați.

    a) $a_n=\frac{(-1)^n}{n}$;

    b) $b_n=n+(-1)^n$;

    c) $c_n=2n+(-1)^n$.

Pentru cei care vor mai mult

  1. Fie $a$ un număr real și șirul $x_1=a$, $x_{n+1}=x_n^2-2x_n+2$, pentru $n\ge 1$.

    a) Arătați că $x_{n+1}-1=(x_n-1)^2$ și $x_{n+1}-x_n=(x_n-1)(x_n-2)$.

    b) Dacă $a\in(1;\ 2)$, arătați că șirul este strict descrescător.

    c) Dacă $a>2$, arătați că șirul este strict crescător.

    d) Pentru ce valori ale lui $a$ șirul este constant?

Întrebări frecvente

Când pot folosi raportul pentru a studia monotonia unui șir?

Numai când toți termenii șirului sunt strict pozitivi. Atunci, dacă aₙ₊₁ / aₙ > 1 pentru orice n, șirul este strict crescător, iar dacă raportul este mai mic decât 1, șirul este strict descrescător. Pentru termeni negativi concluzia se inversează, așa că e mai sigur să folosești diferența.

Cum arăt că un șir nu este monoton?

Găsești trei termeni consecutivi care urcă și apoi coboară sau coboară și apoi urcă, de exemplu a₁ < a₂ și a₂ > a₃. Un singur astfel de contraexemplu ajunge: șirul nu poate fi nici crescător, nici descrescător.

De ce folosim inducția la șirurile date prin recurență?

Când știm doar x₁ și relația xₙ₊₁ = g(xₙ), nu avem o formulă pentru xₙ, deci nu putem calcula direct diferența. Verificăm inegalitatea pentru primii doi termeni și arătăm că ea se transmite de la un pas la următorul, de obicei pentru că funcția g este crescătoare.
