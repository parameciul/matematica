Fișă de lucru: partea întreagă și partea fracționară

Publicat 23 septembrie 2026

Deschide PDF

Apasă «Verifică» lângă un exercițiu. Răspunsurile rămân pe acest dispozitiv.

Reamintim

$\lbrack x\rbrack\ \leq \ x\ < \ \lbrack x\rbrack\ + \ 1$ — partea întreagă a lui $x$ este cel mai mare număr întreg ≤ $x$.

$\{ x\}\ = \ x\ - \ \lbrack x\rbrack$, $0\ \leq \ \{ x\}\ < \ 1$ — partea fracționară a lui $x$.

$x\ = \ \lbrack x\rbrack\ + \ \{ x\}$

$\lbrack x\ + \ n\rbrack\ = \ \lbrack x\rbrack\ + \ n$ și $\{ x\ + \ n\}\ = \ \{ x\}$, oricare ar fi $n\ \in \ {\mathbb{Z}}$.

Nivelul I – Cunoaștere și calcul direct

  1. Calculați $\lbrack 7,3\rbrack$ și $\{ 7,3\}$.

  2. Calculați $\lbrack - 4,6\rbrack$ și $\{ - 4,6\}$.

  3. Calculați $\lbrack 5\rbrack$ și $\{ 5\}$ (5 este număr întreg).

  4. Calculați $\lbrack\sqrt{30}\rbrack$ și $\{\sqrt{30}\}$, știind că $5\ < \ \sqrt{30}\ < \ 6$.

  5. Calculați $\lbrack - \sqrt{2}\rbrack$ și $\{ - \sqrt{2}\}$, știind că $1\ < \ \sqrt{2}\ < \ 2$.

  6. Calculați $\lbrack\frac{17}{4}\rbrack$ și $\{\frac{17}{4}\}$.

  7. Determinați numărul real $x$, știind că $\lbrack x\rbrack\ = \ - 3$ și $\{ x\}\ = \ 0,25$.

Nivelul II – Ecuații și proprietăți

  1. Rezolvați în $\mathbb{R}$ ecuația $\lbrack x\rbrack\ = \ 4$.

  2. Determinați numărul real $x$, știind că $\lbrack x\rbrack\ = \ 10$ și $\{ x\}\ = \ 0,6$.

  3. Rezolvați ecuația $\lbrack 2x\rbrack\ = \ 7$, $x\ \in \ {\mathbb{R}}$.

  4. Rezolvați ecuația $\lbrack x\ - \ 1\rbrack\ = \ 3$.

  5. Arătați că $\{ x\ + \ 7\}\ = \ \{ x\}$, oricare ar fi $x\ \in \ {\mathbb{R}}$.

  6. Rezolvați ecuația ${\lbrack x\rbrack}^{2}\ = \ 9$, pentru $x\ \geq \ 0$.

  7. Rezolvați ecuația $\lbrack 3x\ - \ 2\rbrack\ = \ 4$.

Nivelul III – Ecuații, proprietăți și discuții de caz

  1. Rezolvați ecuația ${\lbrack x\rbrack}^{2}\ - \ 5\lbrack x\rbrack\ + \ 6\ = \ 0$.

  2. Rezolvați ecuația ${\{ x\}}^{2}\ = \ \{ x\}$.

  3. Rezolvați ecuația $\lbrack x\rbrack\ + \ \{ x\}\ = \ 2x\ - \ 3,4$.

  4. Rezolvați inecuația $2\ < \ \lbrack x\rbrack\ < \ 6$, $x\ \in \ {\mathbb{R}}$.

  5. Determinați valorile posibile ale expresiei $E\ = \ \{ x\}\ + \ \{ - x\}$, $x\ \in \ {\mathbb{R}}$.

  6. Arătați că $\lbrack x\ + \ 1\rbrack\ - \ \lbrack x\rbrack\ = \ 1$, oricare ar fi $x\ \in \ {\mathbb{R}}$.

  7. Rezolvați ecuația $\lbrack x\rbrack\ \cdot \ \{ x\}\ = \ 0$.

Nivelul IV – Performanță și tip concurs

  1. Rezolvați ecuația $\lbrack x\rbrack\ + \ \lbrack 2x\rbrack\ = \ 10$, $x\ \in \ {\mathbb{R}}$.

  2. Demonstrați identitatea lui Hermite: $\lbrack x\rbrack\ + \ \lbrack x\ + \ \frac{1}{2}\rbrack\ = \ \lbrack 2x\rbrack$, pentru orice $x\ \in \ {\mathbb{R}}$.

  3. Rezolvați ecuația $\{ x\}\ + \ \{ 2x\}\ = \ 1$, $x\ \in \ \lbrack 0;\ 1)$.

  4. Determinați $x\ \in \ {\mathbb{R}}$ astfel încât ${\lbrack x\rbrack}^{2}\ = \ x\ + \ \lbrack x\rbrack$.
