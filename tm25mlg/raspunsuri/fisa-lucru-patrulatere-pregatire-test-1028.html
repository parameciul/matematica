b) Nu: $OB \neq OD$, deci $O$ nu este mijlocul lui $BD$; diagonalele nu se înjumătățesc, așa că $ABCD$ nu este paralelogram.

4. a) $MN$ este linie mijlocie în $\bigtriangleup ABC$, deci $MN \parallel BC$ și $BC = 2 \cdot MN = 2 \cdot 4,5 = 9\text{ cm}$.

b) $BC = 2 \cdot MN$, deci $MN + 2 \cdot MN = 18$, $3 \cdot MN = 18$, $MN = 6\text{ cm}$ și $BC = 12\text{ cm}$.

NIVEL CONSOLIDAT

5. a) $\frac{\sphericalangle A}{4} = \frac{\sphericalangle B}{5} = \frac{\sphericalangle C}{4} = \frac{\sphericalangle D}{5} = k$, deci $4k + 5k + 4k + 5k = 360{^\circ}$, $18k = 360{^\circ}$, $k = 20{^\circ}$; $\sphericalangle A = 80{^\circ}$, $\sphericalangle B = 100{^\circ}$, $\sphericalangle C = 80{^\circ}$, $\sphericalangle D = 100{^\circ}$.

b) $\sphericalangle A = \sphericalangle C = 80{^\circ}$ și $\sphericalangle B = \sphericalangle D = 100{^\circ}$: unghiurile opuse sunt congruente două câte două, deci $ABCD$ este paralelogram.

6. a) $AB = BC + 6$; $2 \cdot (BC + 6 + BC) = 48$, $BC + 6 + BC = 24$, $2 \cdot BC = 18$, $BC = 9\text{ cm}$.

$AB = CD = 15\text{ cm}$, $BC = AD = 9\text{ cm}$.

b) $\sphericalangle BAD + \sphericalangle ABC = 180{^\circ}$ și $\sphericalangle ABC - \sphericalangle BAD = 40{^\circ}$, deci $2 \cdot \sphericalangle BAD = 140{^\circ}$, $\sphericalangle BAD = 70{^\circ}$.

$\sphericalangle BAD = \sphericalangle BCD = 70{^\circ}$, $\sphericalangle ABC = \sphericalangle ADC = 110{^\circ}$.

7. a) Laturile triunghiului $MNP$ sunt linii mijlocii, deci $P_{ABC} = 2 \cdot P_{MNP} = 2 \cdot 18 = 36\text{ cm}$.

b) $\frac{AB}{3} = \frac{BC}{4} = \frac{AC}{5} = k$, deci $3k + 4k + 5k = 36$, $k = 3$; $AB = 9\text{ cm}$, $BC = 12\text{ cm}$, $AC = 15\text{ cm}$.

$MN = \frac{BC}{2} = 6\text{ cm}$, $NP = \frac{AB}{2} = 4,5\text{ cm}$, $MP = \frac{AC}{2} = 7,5\text{ cm}$ (verificare: $6 + 4,5 + 7,5 = 18$).

NIVEL AVANSAT

8. a) $4 \cdot \sphericalangle A = 4 \cdot \sphericalangle B = 6 \cdot \sphericalangle C = 3 \cdot \sphericalangle D = k$, deci $\sphericalangle A = \frac{k}{4}$, $\sphericalangle B = \frac{k}{4}$, $\sphericalangle C = \frac{k}{6}$, $\sphericalangle D = \frac{k}{3}$.

$\frac{k}{4} + \frac{k}{4} + \frac{k}{6} + \frac{k}{3} = 360{^\circ}$, $\frac{12k}{12} = 360{^\circ}$, $k = 360{^\circ}$; $\sphericalangle A = 90{^\circ}$, $\sphericalangle B = 90{^\circ}$, $\sphericalangle C = 60{^\circ}$, $\sphericalangle D = 120{^\circ}$.

b) Dreptele $AD$ și $BC$ sunt tăiate de secanta $AB$; unghiurile interne de aceeași parte a secantei au $\sphericalangle A + \sphericalangle B = 90{^\circ} + 90{^\circ} = 180{^\circ}$, deci $AD \parallel BC$.

c) Nu. Unghiurile opuse $A$ și $C$ nu sunt congruente ($90{^\circ} \neq 60{^\circ}$), iar într-un paralelogram unghiurile opuse sunt congruente.

9. a) $DA = DE = 7\text{ cm}$, deci $\bigtriangleup ADE$ este isoscel, cu baza $AE$; unghiurile de la bază sunt congruente: $\sphericalangle DAE \equiv \sphericalangle DEA$.

b) $AB \parallel CD$ și $AE$ secantă, deci $\sphericalangle DEA \equiv \sphericalangle EAB$ (alterne interne). Din a) rezultă $\sphericalangle DAE \equiv \sphericalangle EAB$, deci $AE$ este bisectoarea unghiului $BAD$.

c) $CD = AB = 12\text{ cm}$, deci $EC = 12 - 7 = 5\text{ cm}$. $\sphericalangle BAD = 180{^\circ} - 110{^\circ} = 70{^\circ}$, deci $\sphericalangle EAB = \frac{70{^\circ}}{2} = 35{^\circ}$.

10. a) $MN$ este linie mijlocie în $\bigtriangleup ABC$, deci $MN \parallel BC$ și $MN = \frac{BC}{2}$. Atunci $MD = 2 \cdot MN = BC$ și $MD \parallel BC$. Patrulaterul $MBCD$ are două laturi opuse paralele și congruente, deci este paralelogram.

b) $N$ este mijlocul lui $AC$ și al lui $MD$, deci diagonalele patrulaterului $AMCD$ se înjumătățesc; $AMCD$ este paralelogram.

c) $MB = \frac{AB}{2} = 5\text{ cm}$; $P_{MBCD} = 2 \cdot (MB + BC) = 2 \cdot (5 + 14) = 38\text{ cm}$.
