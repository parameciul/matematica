Liniile tabelelor sunt în ordinea: $p,\ q$ = $11,\ 10,\ 01,\ 00$; pentru trei variabile, $p,\ q,\ r$ = $111,\ 110,\ 101,\ 100,\ 011,\ 010,\ 001,\ 000$.

1. a) $1,\ 1,\ 1,\ 1$ – tautologie. b) $1,\ 1,\ 0,\ 1$ – nu este tautologie (falsă pentru $p = 0$, $q = 1$).

c) $p \land \overline{p}$ este mereu falsă, deci $\overline{p \land \overline{p}}$: $1,\ 1,\ 1,\ 1$ – tautologie. d) $p \rightarrow q$ și $\overline{q} \rightarrow \overline{p}$ au ambele valorile $1,\ 0,\ 1,\ 1$, deci echivalența lor: $1,\ 1,\ 1,\ 1$ – tautologie.

2. a) $\overline{p \land q}$: $0,\ 1,\ 1,\ 1$; $\overline{p} \vee \overline{q}$: $0,\ 1,\ 1,\ 1$.

b) Ambele formule sunt false doar pe linia $p = 1$, $q = 1$, $r = 0$; pe celelalte $7$ linii sunt adevărate. Valorile: $1,\ 0,\ 1,\ 1,\ 1,\ 1,\ 1,\ 1$.

3. a) „$35$ nu este divizibil cu $5$ sau nu este divizibil cu $7$”; enunțul: $1$, negația: $0$.

b) „$\sqrt{9} \neq 3$ și $\sqrt{9} \neq - 3$”; enunțul: $1 \vee 0 = 1$, negația: $0$.

c) „$10 \vdots 4$ și $10$ nu este divizibil cu $8$”; enunțul: $0 \rightarrow 0 = 1$, negația: $0$.

d) „$\sqrt{5} \leq 2$ sau $\sqrt{5} \geq 3$”; cum $4 < 5 < 9$, $2 < \sqrt{5} < 3$: enunțul: $1$, negația: $0$.

e) „Triunghiul $ABC$ nu este isoscel și nu este dreptunghic.”

4. a) „$x \leq 1$ sau $x > 5$”. b) „$x \geq - 2$ și $x < 3$”. c) „$x^{2} = 9$ și $x \neq 3$”; este adevărată pentru $x = - 3$.

5. a) Implicația: adevărată. Reciproca („Dacă are diagonalele congruente, atunci este pătrat”): falsă – dreptunghiul. Contrara („Dacă nu este pătrat, atunci nu are diagonalele congruente”): falsă – dreptunghiul. Contrara reciprocei („Dacă nu are diagonalele congruente, atunci nu este pătrat”): adevărată.

b) Toate patru sunt adevărate. Reciproca („Dacă $n^{2}$ este par, atunci $n$ este par”) este adevărată, deoarece contrara ei („Dacă $n$ este impar, atunci $n^{2}$ este impar”) este adevărată: $(2k + 1)^{2} = 2(2k^{2} + 2k) + 1$. Deci „$n$ este par $\Leftrightarrow$ $n^{2}$ este par”.

6. $v(p \vee q) = 1$ și $v(r) = 0$; cum $v(p) = 0$, rezultă $v(q) = 1$. $v(\overline{q} \rightarrow (p \land r)) = v(0 \rightarrow 0) = 1$.

7. a) $\overline{p} \land q$: „Ana nu merge la film și învață”; $\overline{p \vee q}$: „Nu este adevărat că Ana merge la film sau învață”; $p \rightarrow \overline{q}$: „Dacă Ana merge la film, atunci nu învață”; $\overline{p \rightarrow q}$: „Ana merge la film și nu învață”.

b) $\overline{p \vee q}$, deoarece $\overline{p \vee q} \equiv \overline{p} \land \overline{q}$ (De Morgan).

8. $2^{3} = 8$ linii; $2^{n}$ linii. $(p \vee q) \rightarrow r$ este falsă când $r$ este falsă și $p \vee q$ este adevărată: $(p,\ q,\ r) \in \left\{ (1,\ 1,\ 0),\ (1,\ 0,\ 0),\ (0,\ 1,\ 0) \right\}$.

9. Afirmațiile lui Radu și Sorin sunt una negația celeilalte, deci exact una dintre ele este adevărată. Cum doar unul spune adevărul, afirmația lui Tudor este falsă: Tudor a mâncat prăjitura. (Verificare: Radu minte, Sorin spune adevărul, Tudor minte.)
