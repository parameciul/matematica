A. Metoda diferenței

1. a) $a_{n+1}-a_n=3>0$: strict crescător.

b) $b_{n+1}-b_n=4-(n+1)^2-4+n^2=-(2n+1)<0$: strict descrescător.

c) $c_{n+1}-c_n=\frac{3n+2}{n+2}-\frac{3n-1}{n+1}=\frac{(3n+2)(n+1)-(3n-1)(n+2)}{(n+1)(n+2)}=\frac{4}{(n+1)(n+2)}>0$: strict crescător.

2. a) $a_{n+1}-a_n=\frac{3-2n}{n+4}-\frac{5-2n}{n+3}=\frac{(-2n^2-3n+9)-(-2n^2-3n+20)}{(n+3)(n+4)}=\frac{-11}{(n+3)(n+4)}<0$.

b) $b_1=5$, $b_2=2$, $b_3=1$, $b_4=2$ și $b_{n+1}-b_n=2n-5$. Cum $b_2>b_3$ și $b_3<b_4$, șirul nu este monoton. Pentru $n\ge 3$, $2n-5>0$, deci $b_3<b_4<b_5<\ldots$: șirul este strict crescător începând de la rangul $3$.

3. a) $a_{n+1}-a_n=\frac{1}{n+1}>0$: strict crescător.

b) $b_{n+1}=\frac{1}{n+2}+\ldots+\frac{1}{2n}+\frac{1}{2n+1}+\frac{1}{2n+2}$: apar $\frac{1}{2n+1}$ și $\frac{1}{2n+2}$, dispare $\frac{1}{n+1}$. $$b_{n+1}-b_n=\frac{1}{2n+1}+\frac{1}{2n+2}-\frac{1}{n+1}=\frac{1}{2n+1}-\frac{1}{2n+2}=\frac{1}{(2n+1)(2n+2)}>0.$$ Șirul este strict crescător.

4. $a_{n+1}-a_n=2n+1+a$.

a) Cea mai mică valoare a lui $2n+1+a$ se obține pentru $n=1$ și este $3+a$. Șirul este strict crescător dacă și numai dacă $3+a>0$, adică $a>-3$.

b) Pentru $a=-3$: $a_{n+1}-a_n=2n-2\ge 0$, cu egalitate pentru $n=1$ ($a_1=a_2=-2$). Șirul este crescător, dar nu strict crescător.

B. Metoda raportului

5. Termenii sunt strict pozitivi.

a) $\frac{a_{n+1}}{a_n}=\frac{n+2}{4^{n+1}}\cdot\frac{4^n}{n+1}=\frac{n+2}{4n+4}<1$: strict descrescător.

b) $\frac{b_{n+1}}{b_n}=\frac{3^{n+1}}{2n+3}\cdot\frac{2n+1}{3^n}=\frac{6n+3}{2n+3}>1$, pentru că $6n+3>2n+3$: strict crescător.

6. a) $\frac{a_{n+1}}{a_n}=\frac{3n+1}{3n+3}<1$: strict descrescător.

b) $b_{n+1}=\frac{(n+2)\cdot\ldots\cdot(2n)(2n+1)(2n+2)}{4^{n+1}}$, deci $$\frac{b_{n+1}}{b_n}=\frac{(2n+1)(2n+2)}{4(n+1)}=\frac{2n+1}{2}\ge\frac{3}{2}>1:\ \text{strict crescător}.$$

7. a) $\frac{a_{n+1}}{a_n}=\frac{(n+1)\cdot 2^{n+1}}{3^{n+1}}\cdot\frac{3^n}{n\cdot 2^n}=\frac{2(n+1)}{3n}$.

b) $\frac{2(n+1)}{3n}<1\Leftrightarrow 2n+2<3n\Leftrightarrow n>2$. Raportul este $\frac{4}{3}>1$ pentru $n=1$, egal cu $1$ pentru $n=2$ și mai mic decât $1$ pentru $n\ge 3$.

c) $a_1=\frac{2}{3}<a_2=\frac{8}{9}=a_3>a_4=\frac{64}{81}>\ldots$ Șirul nu este monoton. Este strict descrescător începând de la rangul $3$ (descrescător începând de la rangul $2$).

8. a) $a_1=-2$, $a_2=-2$, $a_3=-\frac{8}{3}$. Avem $a_3<a_2$, deci șirul nu este crescător: concluzia este greșită.

b) Toți termenii sunt negativi, deci metoda raportului nu se aplică direct. Din $\frac{a_{n+1}}{a_n}\ge 1$ și $a_n<0$, înmulțind cu $a_n$ se schimbă sensul: $a_{n+1}\le a_n$. Șirul este descrescător (nu strict, pentru că $a_1=a_2$). Altfel: $b_n=-a_n=\frac{2^n}{n}>0$ este crescător, deci $a_n$ este descrescător.

C. Metoda inducției

9. a) $x_2=3>1=x_1$. Din $x_k<x_{k+1}$ rezultă $\frac{x_k+8}{3}<\frac{x_{k+1}+8}{3}$, adică $x_{k+1}<x_{k+2}$: strict crescător.

b) $y_2=6<10=y_1$ și, la fel, din $y_k>y_{k+1}$ rezultă $y_{k+1}>y_{k+2}$: strict descrescător.

c) $z_2=4=z_1$, deci $z_n=4$ pentru orice $n$: șir constant.

Observație: aceeași relație de recurență dă șiruri cu monotonii diferite; contează primul termen. Numărul $4$ verifică $4=\frac{4+8}{3}$.

10. a) $x_1=9>5$. Dacă $x_k>5$, atunci $x_{k+1}=\sqrt{x_k+20}>\sqrt{25}=5$.

b) $x_2=\sqrt{29}<9=x_1$ (pentru că $29<81$). Dacă $x_k>x_{k+1}$, atunci $x_k+20>x_{k+1}+20>0$ și, extrăgând radicalul, $x_{k+1}>x_{k+2}$. Șirul este strict descrescător.

11. a) $x_1=1>0$. Dacă $x_k>0$, atunci $x_{k+1}=\frac{x_k}{1+x_k}>0$.

b) $x_{n+1}-x_n=\frac{x_n-x_n-x_n^2}{1+x_n}=-\frac{x_n^2}{1+x_n}<0$, deoarece $x_n>0$. Șirul este strict descrescător.

c) $x_2=\frac{1}{2}$, $x_3=\frac{1}{3}$, $x_4=\frac{1}{4}$, deci $x_n=\frac{1}{n}$. Dacă $x_k=\frac{1}{k}$, atunci $x_{k+1}=\frac{1/k}{1+1/k}=\frac{1}{k+1}$.

12. a) $x_1=3>2$. Dacă $x_k>2$, atunci $x_{k+1}-2=1-\frac{2}{x_k}=\frac{x_k-2}{x_k}>0$.

b) $x_{n+1}-x_n=3-\frac{2}{x_n}-x_n=\frac{-x_n^2+3x_n-2}{x_n}=-\frac{(x_n-1)(x_n-2)}{x_n}$. Cum $x_n>2$, avem $x_n-1>0$, $x_n-2>0$, $x_n>0$, deci diferența este negativă: strict descrescător.

D. Alegeți metoda

13. a) $a_n=\frac{1}{\sqrt{n+1}+\sqrt{n}}$. Numitorul crește strict, termenii sunt pozitivi, deci șirul este strict descrescător.

b) $b_{n+1}-b_n=1+\frac{1}{n+1}-\frac{1}{n}=1-\frac{1}{n(n+1)}=\frac{n^2+n-1}{n(n+1)}>0$: strict crescător.

c) $c_n=1-\frac{1}{n^2+1}$; $c_{n+1}-c_n=\frac{1}{n^2+1}-\frac{1}{(n+1)^2+1}>0$: strict crescător.

14. a) $a_1=-1<a_2=\frac{1}{2}>a_3=-\frac{1}{3}$: nu este monoton.

b) $b_1=0<b_2=3>b_3=2$: nu este monoton.

c) $c_{n+1}-c_n=2+(-1)^{n+1}-(-1)^n=2-2\cdot(-1)^n\in\{0;\ 4\}$, deci $c_{n+1}-c_n\ge 0$: șirul este crescător, dar nu strict ($c_2=c_3=5$).

Pentru cei care vor mai mult

15. a) $x_{n+1}-1=x_n^2-2x_n+1=(x_n-1)^2$ și $x_{n+1}-x_n=x_n^2-3x_n+2=(x_n-1)(x_n-2)$.

b) Arătăm prin inducție că $1<x_n<2$: dacă $0<x_k-1<1$, atunci $0<(x_k-1)^2<1$, adică $1<x_{k+1}<2$. Atunci $(x_n-1)(x_n-2)<0$: strict descrescător.

c) Prin inducție, $x_n>2$: dacă $x_k-1>1$, atunci $(x_k-1)^2>1$, adică $x_{k+1}>2$. Atunci $(x_n-1)(x_n-2)>0$: strict crescător.

d) Șirul este constant dacă și numai dacă $x_2=x_1$, adică $(a-1)(a-2)=0$: $a=1$ sau $a=2$. (Pentru $a=0$, de exemplu, $x_1=0$ și $x_n=2$ pentru $n\ge 2$: șirul nu este constant.)

Greșeli frecvente de urmărit

  • Metoda raportului folosită pentru termeni negativi sau de semne diferite (ex. 8, 14).
  • Concluzia „strict crescător” când diferența poate fi $0$ (ex. 4 b, 14 c).
  • La 3 b): $b_{n+1}$ scris greșit – se uită că dispare $\frac{1}{n+1}$ și apar doi termeni noi.
  • La inducție: lipsa verificării $x_1<x_2$ (sau $x_1>x_2$) sau a mărginirii folosite la pas (ex. 10, 12).
  • Șir nemonoton afirmat fără a da trei termeni concreți care „urcă și coboară”.
