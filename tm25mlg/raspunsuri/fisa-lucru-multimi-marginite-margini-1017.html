Ex. 3. a) $\frac{2n + 3}{n + 1} = \frac{2(n + 1) + 1}{n + 1} = 2 + \frac{1}{n + 1}$. b) $0 < \frac{1}{n + 1} \leq 1 \Rightarrow 2 < x \leq 3$. c) Pentru $n = 0$ obținem $3 \in A$, iar $3$ este majorant, deci $\max A = 3$. d) $2$ este minorant; pentru $\varepsilon > 0$: $2 + \frac{1}{n + 1} < 2 + \varepsilon \Leftrightarrow n + 1 > \frac{1}{\varepsilon}$, inecuație care are soluții în $\mathbb{N}$. Deci $\inf A = 2$; cum $2 \notin A$, mulțimea $A$ nu are minim.

Ex. 4. Din $x^{2} + 1 \geq 2|x|$ rezultă $\left| \frac{x}{x^{2} + 1} \right| \leq \frac{1}{2}$, deci $A \subset \left\lbrack - \frac{1}{2},\frac{1}{2} \right\rbrack$ este mărginită. Pentru $x = 1$ obținem $\frac{1}{2} \in A$, iar pentru $x = - 1$ obținem $- \frac{1}{2} \in A$. Deci $\max A = \frac{1}{2}$, $\min A = - \frac{1}{2}$.
