A. Criteriul majorării

1. a) $\left|\frac{n\cos n}{n^2+1}\right|\le\frac{n}{n^2+1}\le\frac{1}{n}\to 0$, deci limita este $0$.

b) $|x_n-2|=\frac{|\sin n+2|}{2n+1}\le\frac{3}{2n+1}\to 0$, deci limita este $2$.

c) $x_n-\frac{1}{3}=\frac{3(-1)^n n-2}{3(3n^2+2)}$, deci $\left|x_n-\frac{1}{3}\right|\le\frac{3n+2}{3(3n^2+2)}\to 0$; limita este $\frac{1}{3}$.

2. a) $\sin n\le 1$, deci $x_n\ge n^2-5n=n(n-5)\to+\infty$; limita este $+\infty$.

b) Fiecare dintre cei $n$ termeni este cel puțin $\frac{1}{\sqrt{n}}$, deci $x_n\ge\frac{n}{\sqrt{n}}=\sqrt{n}\to+\infty$; limita este $+\infty$.

c) Bernoulli, cu $a=\frac{1}{n}$ și exponentul $n^2$: $x_n\ge 1+n^2\cdot\frac{1}{n}=1+n\to+\infty$; limita este $+\infty$.

d) $\cos n\le 1$, deci $x_n\le 2-\sqrt{n}\to-\infty$; limita este $-\infty$.

3. a) Adevărat: $|x_n-0|\le\frac{1}{n}\to 0$.

b) Fals: $x_n=0$.

c) Adevărat: consecința criteriului majorării.

d) Fals: $x_n=1$, $y_n=\frac{1}{n}$.

e) Fals: $x_n=(-1)^n$.

B. Criteriul cleștelui

4. a) $\frac{\sqrt{n}-1}{\sqrt{n}}<x_n\le 1$, iar $\frac{\sqrt{n}-1}{\sqrt{n}}\to 1$; limita este $1$.

b) $\frac{n\sqrt{2}-1}{n+1}<x_n\le\frac{n\sqrt{2}}{n+1}$; ambele margini tind la $\sqrt{2}$, deci limita este $\sqrt{2}$.

c) $\frac{\sqrt{4n^2+n}-1}{n}<x_n\le\frac{\sqrt{4n^2+n}}{n}=\sqrt{4+\frac{1}{n}}$; ambele margini tind la $2$, deci limita este $2$.

5. a) $\frac{n}{\sqrt{n^2+n}}\le x_n\le\frac{n}{\sqrt{n^2+1}}$; limita este $1$.

b) $\frac{1+2+\ldots+n}{n^2+n}\le x_n\le\frac{1+2+\ldots+n}{n^2+1}$, adică $\frac{1}{2}\le x_n\le\frac{n(n+1)}{2(n^2+1)}$; limita este $\frac{1}{2}$.

c) $\frac{n}{n^2+n}\le x_n\le\frac{n}{n^2+1}$; limita este $0$.

6. a) $5\le x_n\le 5\sqrt[n]{2}$; limita este $5$.

b) $4^n\le 1+3^n+4^n\le 3\cdot 4^n$, deci $4\le x_n\le 4\sqrt[n]{3}$; limita este $4$.

c) $n\le 3^n$, deci $3\le x_n\le 3\sqrt[n]{2}$; limita este $3$.

7. a) Marginile $0$ și $1$ au limite diferite; criteriul cleștelui cere ca ambele margini să aibă aceeași limită.

b) $x_{2n}=\frac{2n}{2n+1}\to 1$ și $x_{2n+1}=0\to 0$. Două subșiruri au limite diferite, deci șirul $(x_n)$ nu are limită.

C. Proprietatea lui Weierstrass

8. a) $x_{n+1}-x_n=\frac{1}{2n+1}+\frac{1}{2n+2}-\frac{1}{n+1}=\frac{1}{2n+1}-\frac{1}{2n+2}>0$: șirul este crescător. Suma are $n$ termeni, fiecare între $\frac{1}{2n}$ și $\frac{1}{n+1}$, deci $\frac{1}{2}\le x_n\le\frac{n}{n+1}<1$.

b) $x_{n+1}-x_n=\frac{1}{(n+1)^2}>0$: crescător. $x_n\le 1+\left(1-\frac{1}{2}\right)+\left(\frac{1}{2}-\frac{1}{3}\right)+\ldots+\left(\frac{1}{n-1}-\frac{1}{n}\right)=2-\frac{1}{n}<2$, iar $x_n\ge 1$.

c) Crescător (se adaugă termeni pozitivi). Din $k!\ge 2^{k-1}$: $x_n\le 1+\frac{1}{2}+\ldots+\frac{1}{2^{n-1}}=2-\frac{1}{2^{n-1}}<2$, iar $x_n\ge 1$.

d) Termenii sunt pozitivi și $\frac{x_{n+1}}{x_n}=\frac{2n+1}{2n+2}<1$: descrescător. $0<x_n\le x_1=\frac{1}{2}$.

În toate cazurile, din proprietatea lui Weierstrass, șirul este convergent.

9. a) $x_2=\sqrt{7}$, $x_3=\sqrt{4+3\sqrt{7}}$.

b) Inducție: $x_1=1\in(0,4)$; dacă $0<x_n<4$, atunci $0<x_{n+1}=\sqrt{3x_n+4}<\sqrt{16}=4$.

c) $x_{n+1}^2-x_n^2=3x_n+4-x_n^2=(4-x_n)(1+x_n)>0$ și termenii sunt pozitivi, deci $x_{n+1}>x_n$.

d) Crescător și mărginit, deci convergent, cu $\ell\ge 1$. Din $\ell=\sqrt{3\ell+4}$: $\ell^2-3\ell-4=0$, $\ell\in\{-1,4\}$, deci $\ell=4$.

10. a) $x_2=\frac{3}{2}+\frac{1}{3}=\frac{11}{6}$.

b) Prin inducție $x_n>0$. Din inegalitatea mediilor, $x_{n+1}=\frac{x_n}{2}+\frac{1}{x_n}\ge 2\sqrt{\frac{x_n}{2}\cdot\frac{1}{x_n}}=\sqrt{2}$, iar $x_1=3\ge\sqrt{2}$.

c) $x_{n+1}-x_n=\frac{1}{x_n}-\frac{x_n}{2}=\frac{2-x_n^2}{2x_n}\le 0$.

d) Descrescător și minorat de $\sqrt{2}$, deci convergent, cu $\ell\ge\sqrt{2}$. Din $\ell=\frac{\ell}{2}+\frac{1}{\ell}$: $\ell^2=2$, deci $\ell=\sqrt{2}$.

11. a) $x_2=4$, $x_3=16$, $x_4=256$.

b) Elevul trece la limită în recurență fără să știe că șirul are limită finită.

c) Prin inducție $x_n\ge 2$, deci $x_{n+1}-x_n=x_n(x_n-1)>0$: crescător. $x_1=2\ge 2^1$; dacă $x_n\ge 2^n$, atunci $x_{n+1}=x_n^2\ge 2^{2n}\ge 2^{n+1}$. Din criteriul majorării, limita este $+\infty$.

D. Numărul e

12. a) $u_n=\frac{5}{n}$, $L=5$: limita este $e^5$.

b) $u_n=-\frac{2}{n}$, $L=-2$: limita este $e^{-2}$.

c) $u_n=\frac{1}{n+1}$, $L=\lim\limits_{n\to\infty}\frac{n}{n+1}=1$: limita este $e$.

d) $u_n=\frac{4}{2n-3}$, $L=\lim\limits_{n\to\infty}\frac{4(n+5)}{2n-3}=2$: limita este $e^2$.

e) $u_n=\frac{3n+1}{n^2-2n}$, $L=\lim\limits_{n\to\infty}\frac{n(3n+1)}{n^2-2n}=3$: limita este $e^3$.

f) $u_n=-\frac{3}{n^2+2}$, $L=\lim\limits_{n\to\infty}\frac{-3n^2}{n^2+2}=-3$: limita este $e^{-3}$.

13. a) $1^{\infty}$, $L=\lim\limits_{n\to\infty}\frac{n}{n^2}=0$: limita este $e^0=1$.

b) $1^{\infty}$, $u_n=\frac{2}{n}$, $L=\lim\limits_{n\to\infty}2\sqrt{n}=+\infty$: limita este $+\infty$.

c) Baza tinde la $\frac{1}{2}$: nu este cazul $1^{\infty}$. Pentru $n\ge 1$, $0<\frac{n+1}{2n+1}\le\frac{2}{3}$, deci $0<x_n\le\left(\frac{2}{3}\right)^n\to 0$; limita este $0$.

d) Baza tinde la $3$. Pentru $n\ge 3$, $\frac{3n+1}{n+2}\ge 2$, deci $x_n\ge 2^n\to+\infty$; limita este $+\infty$.

14. $u_n=\frac{a+2}{n-2}$, $L=a+2=5$, deci $a=3$.

15. a) Al doilea elev: $\left(1+\frac{1}{n}\right)^{3n}=\left[\left(1+\frac{1}{n}\right)^n\right]^3\to e^3$.

b) Primul elev tratează cazul exceptat $1^{\infty}$ ca pe $1$: baza nu este egală cu $1$, doar tinde la $1$, în timp ce exponentul crește nelimitat.

16. a) $n\ln\left(1+\frac{2}{n}\right)=2\cdot\frac{\ln(1+u_n)}{u_n}$, cu $u_n=\frac{2}{n}$; limita este $2$.

b) $u_n=\frac{1}{n}$: $\frac{3^{u_n}-1}{u_n}\to\ln 3$; limita este $\ln 3$.

c) $u_n=\frac{1}{n}$: $\frac{e^{u_n}-1}{u_n}\to 1$; limita este $1$.

E. Criteriul raportului

17. a) $\frac{a_{n+1}}{a_n}=\frac{1}{2}\left(\frac{n+1}{n}\right)^3\to\frac{1}{2}<1$: limita este $0$.

b) $\frac{a_{n+1}}{a_n}=2\left(\frac{n}{n+1}\right)^n\to\frac{2}{e}<1$: limita este $0$.

c) $\frac{a_{n+1}}{a_n}=\frac{n+1}{4}\to+\infty$: limita este $+\infty$.

d) $\frac{a_{n+1}}{a_n}=\frac{(2n+1)(2n+2)}{(n+1)^2}=\frac{2(2n+1)}{n+1}\to 4>1$: limita este $+\infty$.

e) $\frac{a_{n+1}}{a_n}=\frac{(2n+3)(n+3)}{(n+4)(2n+1)}\to 1$: criteriul nu decide. Direct, $\frac{2n+1}{n+3}\to 2$.

F. Alegeți criteriul

18. a) Criteriul majorării: $\left|x_n-\frac{1}{2}\right|=\frac{|6\cos n-1|}{2(2n^2+1)}\le\frac{7}{2(2n^2+1)}\to 0$; limita este $\frac{1}{2}$.

b) Numărul $e$: $u_n=\frac{2}{n^2+1}$, $L=2$; limita este $e^2$.

c) Împărțim la $n!$: $x_n=\frac{1+\frac{2^n}{n!}}{1+\frac{3^n}{n!}}$, iar $\frac{2^n}{n!}\to 0$, $\frac{3^n}{n!}\to 0$ (criteriul raportului); limita este $1$.

d) Criteriul cleștelui: $2^n\le n^2+2^n\le 2\cdot 2^n$, deci $2\le x_n\le 2\sqrt[n]{2}$; limita este $2$.

e) Weierstrass: $x_n>3$ (inducție: $x_{n+1}>\sqrt{9}=3$) și $x_{n+1}^2-x_n^2=-(x_n-3)(x_n+1)<0$, deci șirul este descrescător și minorat. Din $\ell=\sqrt{2\ell+3}$, $\ell\in\{-1,3\}$ și $\ell\ge 3$; limita este $3$.

f) Nu este nevoie de un criteriu: $\frac{n(n+1)(2n+1)}{6n^3}\to\frac{1}{3}$.

Pentru cei care vor mai mult

19. a) Numerele nu sunt toate egale, deci $\sqrt[n+1]{1\cdot\left(1+\frac{1}{n}\right)^n}<\frac{1+n\left(1+\frac{1}{n}\right)}{n+1}=1+\frac{1}{n+1}$. Ridicăm la puterea $n+1$: $e_n<e_{n+1}$.

b) $e_n=\displaystyle\sum_{k=0}^{n}C_n^k\frac{1}{n^k}$ și $C_n^k\frac{1}{n^k}=\frac{1}{k!}\cdot\frac{n(n-1)\cdots(n-k+1)}{n^k}\le\frac{1}{k!}\le\frac{1}{2^{k-1}}$, deci $e_n\le 1+1+\frac{1}{2}+\ldots+\frac{1}{2^{n-1}}<3$.

c) Șirul este crescător și mărginit, deci convergent (Weierstrass).

20. $\frac{a_{n+1}}{a_n}=a\left(\frac{n}{n+1}\right)^n\to\frac{a}{e}$. Pentru $a<e$, limita este $0$; pentru $a>e$, limita este $+\infty$. Pentru $a=e$ criteriul nu decide; raportul este $\frac{e}{e_n}>1$, deci șirul este crescător și nu tinde la $0$ (se poate arăta că limita este $+\infty$).

21. $kx-1<[kx]\le kx$. Adunând pentru $k=1,\ldots,n$: $\frac{n(n+1)}{2}x-n<S_n\le\frac{n(n+1)}{2}x$. Împărțim la $n^2$ și aplicăm criteriul cleștelui: limita este $\frac{x}{2}$.
