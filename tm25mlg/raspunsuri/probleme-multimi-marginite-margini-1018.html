3. a) $\min A = \inf A = 0$, $\sup A = 1$, $A$ nu are maxim.

b) Elementele sunt $- 1,\mkern9mu\frac{1}{2},\mkern9mu - \frac{1}{3},\mkern9mu\frac{1}{4},\ldots$; $\min B = \inf B = - 1$, $\max B = \sup B = \frac{1}{2}$.

c) $\max C = \sup C = 1$ (pentru $n = 0$), $\inf C = 0$, $C$ nu are minim.

d) $\inf D = - 1$, $D$ nu are minim; $\max D = \sup D = 5$.

e) $n^{2} - 3n = n(n - 3)$ ia valorile $0, - 2, - 2,0,4,10,\ldots$; $\min E = \inf E = - 2$; pentru $n \geq 4$, $n^{2} - 3n \geq n$, deci $E$ nu este majorată: $\sup E = + \infty$, $E$ nu are maxim.

4. a) $\frac{3n - 1}{n + 2} = \frac{3(n + 2) - 7}{n + 2} = 3 - \frac{7}{n + 2}$. b) Elementele cresc odată cu $n$, deci $\min A = - \frac{1}{2}$ (pentru $n = 0$). c) $x < 3,\mkern9mu\forall x \in A$; pentru $\varepsilon > 0$: $3 - \frac{7}{n + 2} > 3 - \varepsilon \Leftrightarrow n + 2 > \frac{7}{\varepsilon}$, inecuație cu soluții în $\mathbb{N}$; deci $\sup A = 3$. d) $3 \notin A$, deci $A$ nu are maxim.

5. Pentru $y = 1$ se obține $x = 0$, deci $1 \in A$. Pentru $y \neq 1$, condiția $\Delta \geq 0$ devine $y^{2} - 4(y - 1)^{2} = (2 - y)(3y - 2) \geq 0 \Leftrightarrow y \in \left\lbrack \frac{2}{3},2 \right\rbrack$. Deci $A = \left\lbrack \frac{2}{3},2 \right\rbrack$, $\min A = \frac{2}{3}$ (pentru $x = 1$), $\max A = 2$ (pentru $x = - 1$).

6. $x^{2} - (m + 1)x + m = (x - 1)(x - m)$. Pentru $m > 1$: $A = \lbrack 1,m\rbrack$, $m - 1 = 3 \Rightarrow m = 4$; pentru $m < 1$: $A = \lbrack m,1\rbrack$, $1 - m = 3 \Rightarrow m = - 2$; pentru $m = 1$: $A = \left\{ 1 \right\}$. Deci $m \in \left\{ - 2,4 \right\}$.

7. a) $\sqrt{n + 1} - \sqrt{n} = \frac{1}{\sqrt{n + 1} + \sqrt{n}} \in (0,1\rbrack$; $A$ este mărginită, $\max A = \sup A = 1$ (pentru $n = 0$), $\inf A = 0$ (pentru $\varepsilon > 0$, $\frac{1}{\sqrt{n + 1} + \sqrt{n}} < \frac{1}{2\sqrt{n}} < \varepsilon$ dacă $n > \frac{1}{4\varepsilon^{2}}$), $A$ nu are minim.

b) $n + \frac{1}{n} \geq 2$, cu egalitate pentru $n = 1$: $\min B = \inf B = 2$; $n + \frac{1}{n} > n$, deci $B$ nu este majorată: $\sup B = + \infty$; $B$ nu este mărginită.

c) $\sin x + \cos x = \sqrt{2}\sin\left( x + \frac{\pi}{4} \right)$, deci $C = \left\lbrack - \sqrt{2},\sqrt{2} \right\rbrack$: mărginită, $\min C = - \sqrt{2}$, $\max C = \sqrt{2}$.

8. a) Fals: $(0,1)$ este mărginită, dar nu are maxim. b) Adevărat: maximul este un majorant care aparține mulțimii, deci este cel mai mic majorant. c) Adevărat: dacă $A$ ar avea maxim, atunci $\sup A = \max A \in A$. d) Adevărat (principiul bunei ordonări a lui $\mathbb{N}$). e) Fals: marginea superioară în $\mathbb{R}$ este $\sqrt{2} \notin {\mathbb{Q}}$; în $\mathbb{Q}$ axioma lui Cantor nu are loc.

9. Fie $s = \sup A$, $t = \sup B$. Din $a \leq s$, $b \leq t$ rezultă $a + b \leq s + t$, deci $s + t$ este majorant al lui $A + B$. Pentru $\varepsilon > 0$ există $a \in A$ cu $a > s - \frac{\varepsilon}{2}$ și $b \in B$ cu $b > t - \frac{\varepsilon}{2}$; atunci $a + b > (s + t) - \varepsilon$. Deci $\sup(A + B) = s + t$.
