RĂSPUNSURI ȘI INDICAȚII

Secțiunea A

1. $A = (4 - 2\sqrt{3}) - 2\sqrt{3} + (\sqrt{3} - 1) = 3 - 3\sqrt{3}$, irațional: enunțul nu se verifică.

2. $x \leq 3$ și $x > - 14$: $S = ( - 14,\ 3\rbrack$.

3. $\frac{3x + 1}{x - 2} = 3 + \frac{7}{x - 2} \in {\mathbb{Z}} \Rightarrow x \in \{ - 5,\ 1,\ 3,\ 9\}$.

4. a) $\Delta = 5 - 4m > 0 \Rightarrow m < \frac{5}{4}$;

b) $2m^{2} - 4m + 3 = 7 \Rightarrow m = 1 - \sqrt{3}$ (cealaltă rădăcină nu dă rădăcini reale).

Secțiunea B

5. a) Dreaptă prin $(6,0)$ și $(0,3)$;

b) $A = 9$, $P = 9 + 3\sqrt{5}$.

6. a) $\widehat{B} = 30{^\circ}$, $\widehat{C} = 60{^\circ}$, $AD = 3\sqrt{3}\text{ cm}$;

b) $E = \frac{1}{4} + \frac{3}{4} - \frac{3}{2} = - \frac{1}{2}$.

7. a) $AB = 2\sqrt{13}$, $AC = 3\sqrt{2}$, $BC = \sqrt{58}$: laturile sunt diferite două câte două, triunghiul nu este isoscel;

b) $M_{AB}(1,3)$, mediana din $C$ este $5$.

Secțiunea C

8. $n^{4} + 4 = (n^{2} - 2n + 2)(n^{2} + 2n + 2)$: prim doar pentru $n = 1$.

9. $t = \frac{x - 2}{2} \in {\mathbb{Z}}$, $t \in \{ 1,\ 2,\ 3\}$: $3$ soluții.

10. Rotația de $90{^\circ}$ în jurul lui $A$ duce $\Delta ABM$ în $\Delta ADN$: $MN = BM + DN$, deci perimetrul este $2a$.
