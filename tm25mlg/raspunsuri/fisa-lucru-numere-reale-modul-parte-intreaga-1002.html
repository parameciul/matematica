RĂSPUNSURI ȘI INDICAȚII

Secțiunea A

1. $7 + 5 - 8 = 4$.

2. $\sqrt{5} < 3$ și $\sqrt{5} > 2$, deci suma este $\left( 3 - \sqrt{5} \right) + \left( \sqrt{5} - 2 \right) = 1$.

3. $\left\lbrack \text{3,7} \right\rbrack = 3$; $\left\lbrack - \text{3,7} \right\rbrack = - 4$; $\left\{ \text{3,7} \right\} = \text{0,7}$; $\left\{ - \text{3,7} \right\} = \text{0,3}$.

4. $16 < 20 < 25 \Rightarrow 4 < \sqrt{20} < 5$: $\left\lbrack \sqrt{20} \right\rbrack = 4$; $\left\lbrack - \sqrt{20} \right\rbrack = - 5$; $\left\{ \sqrt{20} \right\} = 2\sqrt{5} - 4$.

5. a) F ($a = 1$, $b = - 1$: $0 \neq 2$); b) A; c) F ($x = - 1$: $\sqrt{1} = 1 \neq - 1$); d) A ($2 \in {\mathbb{Z}}$); e) F ($x = \text{0,5}$: $1 \neq 0$).

6. Pentru $x \in \lbrack - 1,\ 3\rbrack$: $|x - 3| = 3 - x$ și $|x + 1| = x + 1$, deci suma este $4$.

7. $x - 2 = 5$ sau $x - 2 = - 5$; $S = \{ - 3,\ 7\}$.

8. a) $S = \varnothing$ (un modul nu poate fi negativ);

b) $3x - 6 = 0$, $S = \{ 2\}$.

9. $- 2 \leq x < - 1$, adică $x \in \lbrack - 2,\ - 1)$.

10. a) $- 3 \leq x - 1 \leq 3$, $S = \lbrack - 2,\ 4\rbrack$;

b) $\lbrack x\rbrack \leq 2 \Leftrightarrow x < 3$, $S = ( - \infty,\ 3)$.

Secțiunea B

11. $N = \left( \sqrt{2} - 1 \right) + \left( \sqrt{3} - \sqrt{2} \right) + \left( 2 - \sqrt{3} \right) = 1 \in {\mathbb{N}}$.

12. Expresia este $\sqrt{(x - 1)^{2}} + \sqrt{(x - 4)^{2}} = |x - 1| + |x - 4| = (x - 1) + (4 - x) = 3$.

13. $\left\lbrack \sqrt{n} \right\rbrack = 1$ pentru $n \in \{ 1,\ 2,\ 3\}$; $\left\lbrack \sqrt{n} \right\rbrack = 2$ pentru $n \in \{ 4,\ \ldots,\ 8\}$; $\left\lbrack \sqrt{n} \right\rbrack = 3$ pentru $n \in \{ 9,\ 10\}$; $S = 3 \cdot 1 + 5 \cdot 2 + 2 \cdot 3 = 19$.

14. a) $|a + b| \leq |a| + |b| \leq 1 + 1 = 2$;

b) $|ab| = |a| \cdot |b| \leq 1 \cdot 1 = 1$.

15. a) Dacă $k < x < k + 1$, $k \in {\mathbb{Z}}$, atunci $- k - 1 < - x < - k$, deci $\lbrack x\rbrack + \lbrack - x\rbrack = k - k - 1 = - 1$.

b) $1 + ( - 2) + \left( \sqrt{3} - 1 \right) + \left( 2 - \sqrt{3} \right) = 0$.

16. $2x - 3 = x + 1 \Rightarrow x = 4$; $2x - 3 = - x - 1 \Rightarrow x = \frac{2}{3}$; $S = \{\frac{2}{3},\ 4\}$.

17. Condiția $2x - 1 \geq 0 \Leftrightarrow x \geq \frac{1}{2}$. $x - 3 = 2x - 1 \Rightarrow x = - 2$ (nu convine); $3 - x = 2x - 1 \Rightarrow x = \frac{4}{3}$ (convine); $S = \{\frac{4}{3}\}$.

18. $x < 1$: $3 - 2x = 3 \Rightarrow x = 0$ ✓; $1 \leq x < 2$: $1 = 3$, fals; $x \geq 2$: $2x - 3 = 3 \Rightarrow x = 3$ ✓; $S = \{ 0,\ 3\}$.

19. $2 \leq \frac{2x + 1}{3} < 3 \Leftrightarrow 6 \leq 2x + 1 < 9 \Leftrightarrow \frac{5}{2} \leq x < 4$; $S = \lbrack\frac{5}{2},\ 4)$.

20. $2x - 5 < - 3$ sau $2x - 5 > 3$ $\Leftrightarrow$ $x < 1$ sau $x > 4$; $S = ( - \infty,\ 1) \cup (4,\ + \infty)$.

21. a) $|x - 2| < 4 \Leftrightarrow x \in ( - 2,\ 6)$ și $|x - 2| \geq 1 \Leftrightarrow x \in ( - \infty,\ 1\rbrack \cup \lbrack 3,\ + \infty)$, deci $A = ( - 2,\ 1\rbrack \cup \lbrack 3,\ 6)$.

b) $A \cap {\mathbb{Z}} = \{ - 1,\ 0,\ 1,\ 3,\ 4,\ 5\}$.

22. $- 3 \leq 2\lbrack x\rbrack - 1 \leq 3 \Leftrightarrow - 1 \leq \lbrack x\rbrack \leq 2 \Leftrightarrow - 1 \leq x < 3$; $S = \lbrack - 1,\ 3)$.

Secțiunea C

23. $x + 2y = (x - 2) + 2(y + 1)$, deci $|x + 2y| \leq |x - 2| + 2|y + 1| \leq 1 + 2 \cdot 2 = 5$.

24. a) $E(x) = |1 - x| + |x + 2| \geq \left| (1 - x) + (x + 2) \right| = 3$, cu egalitate dacă $1 - x$ și $x + 2$ au același semn, adică $x \in \lbrack - 2,\ 1\rbrack$.

b) $m < 3$: nicio soluție; $m = 3$: o infinitate de soluții ($x \in \lbrack - 2,\ 1\rbrack$); $m > 3$: două soluții.

25. $|x - 2| - 3 = \pm 1 \Rightarrow |x - 2| = 4$ sau $|x - 2| = 2$; $S = \{ - 2,\ 0,\ 4,\ 6\}$.

26. $\frac{3x - 1}{2} = k \in {\mathbb{Z}} \Rightarrow x = \frac{2k + 1}{3}$; $k \leq \frac{2k + 1}{3} < k + 1 \Leftrightarrow - 2 < k \leq 1$, deci $k \in \{ - 1,\ 0,\ 1\}$; $S = \{ - \frac{1}{3},\ \frac{1}{3},\ 1\}$.

27. $x = k + f$, $k \in {\mathbb{Z}}$, $f \in \lbrack 0,\ 1)$: $k + 2f = 3 \Rightarrow f = \frac{3 - k}{2} \in \lbrack 0,\ 1) \Leftrightarrow 1 < k \leq 3$; $k = 2 \Rightarrow x = \frac{5}{2}$, $k = 3 \Rightarrow x = 3$; $S = \{\frac{5}{2},\ 3\}$.

28. $x < - 1$: $- 3 \geq 1$, fals; $- 1 \leq x < 2$: $2x - 1 \geq 1 \Rightarrow x \in \lbrack 1,\ 2)$; $x \geq 2$: $3 \geq 1$, adevărat; $S = \lbrack 1,\ + \infty)$.

29. a) $x = \text{2,3}$: $2 + 2 = 4 = \left\lbrack \text{4,6} \right\rbrack$; $x = \text{2,7}$: $2 + 3 = 5 = \left\lbrack \text{5,4} \right\rbrack$. Cu $x = k + f$: dacă $f \in \lbrack 0,\ \frac{1}{2})$, ambii membri sunt $2k$; dacă $f \in \lbrack\frac{1}{2},\ 1)$, ambii membri sunt $2k + 1$.

b) $\lbrack 2x\rbrack = 5 \Leftrightarrow 5 \leq 2x < 6$; $S = \lbrack\frac{5}{2},\ 3)$.

30. a) $\left\lbrack \sqrt{n} \right\rbrack = k \Leftrightarrow k^{2} \leq n < (k + 1)^{2}$, adică $n \in \{ k^{2},\ k^{2} + 1,\ \ldots,\ k^{2} + 2k\}$: $2k + 1$ numere.

b) Numerele $1,\ 2,\ \ldots,\ 99$ corespund valorilor $k = 1,\ 2,\ \ldots,\ 9$ (pentru $k = 9$: $n = 81,\ \ldots,\ 99$), deci $S = 1 \cdot 3 + 2 \cdot 5 + 3 \cdot 7 + \ldots + 9 \cdot 19 = 615$.
