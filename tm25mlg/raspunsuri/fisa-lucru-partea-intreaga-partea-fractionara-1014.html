NIVELUL I – Cunoaștere și calcul direct

1. Calculați $\lbrack 7,3\rbrack$ și $\{ 7,3\}$.

Rezolvare: $\lbrack 7,3\rbrack\ = \ 7$, $\{ 7,3\}\ = \ 0,3$.

2. Calculați $\lbrack - 4,6\rbrack$ și $\{ - 4,6\}$.

Rezolvare: Cel mai mare întreg ≤ -4,6 este -5, deci $\lbrack - 4,6\rbrack\ = \ - 5$, $\{ - 4,6\}\ = \ - 4,6 - ( - 5)\ = \ 0,4$.

3. Calculați $\lbrack 5\rbrack$ și $\{ 5\}$ (5 este număr întreg).

Rezolvare: $\lbrack 5\rbrack\ = \ 5$, $\{ 5\}\ = \ 0$ — orice număr întreg are partea fracționară egală cu 0.

4. Calculați $\lbrack\sqrt{30}\rbrack$ și $\{\sqrt{30}\}$, știind că $5\ < \ \sqrt{30}\ < \ 6$.

Rezolvare: $\lbrack\sqrt{30}\rbrack\ = \ 5$, $\{\sqrt{30}\}\ = \ \sqrt{30}\ - \ 5$.

5. Calculați $\lbrack - \sqrt{2}\rbrack$ și $\{ - \sqrt{2}\}$, știind că $1\ < \ \sqrt{2}\ < \ 2$.

Rezolvare: Din $1\ < \ \sqrt{2}\ < \ 2$ rezultă $- 2\ < \ - \sqrt{2}\ < \ - 1$, deci $\lbrack - \sqrt{2}\rbrack\ = \ - 2$ și $\{ - \sqrt{2}\}\ = \ - \sqrt{2}\ - ( - 2)\ = \ 2\ - \ \sqrt{2}$.

6. Calculați $\lbrack\frac{17}{4}\rbrack$ și $\{\frac{17}{4}\}$.

Rezolvare: $\frac{17}{4}\ = \ 4,25$, deci $\lbrack\frac{17}{4}\rbrack\ = \ 4$ și $\{\frac{17}{4}\}\ = \ 0,25$.

7. Determinați numărul real x, știind că $\lbrack x\rbrack\ = \ - 3$ și $\{ x\}\ = \ 0,25$.

Rezolvare: Folosim $x\ = \ \lbrack x\rbrack\ + \ \{ x\}\ = \ - 3\ + \ 0,25\ = \ - 2,75$.

NIVELUL II – Ecuații și proprietăți

8. Rezolvați în $\mathbb{R}$ ecuația $\lbrack x\rbrack\ = \ 4$.

Rezolvare: Din definiție, $\lbrack x\rbrack\ = \ 4$ ≤ $x\ < \ 5$, deci soluția este $x\ \in \ \lbrack 4;\ 5)$.

9. Determinați numărul real x, știind că $\lbrack x\rbrack\ = \ 10$ și $\{ x\}\ = \ 0,6$.

Rezolvare: $x\ = \ \lbrack x\rbrack\ + \ \{ x\}\ = \ 10\ + \ 0,6\ = \ 10,6$.

10. Rezolvați ecuația $\lbrack 2x\rbrack\ = \ 7$, $x\ \in \ {\mathbb{R}}$.

Rezolvare: $\lbrack 2x\rbrack\ = \ 7$ ⇒ $2x\ \in \ \lbrack 7;\ 8)$ ⇒ $x\ \in \ \lbrack 3,5;\ 4)$.

11. Rezolvați ecuația $\lbrack x\ - \ 1\rbrack\ = \ 3$.

Rezolvare: $x\ - \ 1\ \in \ \lbrack 3;\ 4)$ ⇒ $x\ \in \ \lbrack 4;\ 5)$.

12. Arătați că $\{ x\ + \ 7\}\ = \ \{ x\}$, oricare ar fi $x\ \in \ {\mathbb{R}}$.

Rezolvare: Cum 7 este întreg, $\lbrack x\ + \ 7\rbrack\ = \ \lbrack x\rbrack\ + \ 7$, deci $\{ x\ + \ 7\}\ = \ (x\ + \ 7)\ - \ \lbrack x\ + \ 7\rbrack\ = \ x\ + \ 7\ - \ \lbrack x\rbrack\ - \ 7\ = \ x\ - \ \lbrack x\rbrack\ = \ \{ x\}$.

13. Rezolvați ecuația ${\lbrack x\rbrack}^{2}\ = \ 9$, pentru $x\ \geq \ 0$.

Rezolvare: Notăm $n\ = \ \lbrack x\rbrack$. Din $n^{2}\ = \ 9$ obținem $n\ = \ 3$ sau $n\ = \ - 3$; cum $x\ \geq \ 0$ avem $n\ \geq \ 0$, deci $n\ = \ 3$ și $x\ \in \ \lbrack 3;\ 4)$.

14. Rezolvați ecuația $\lbrack 3x\ - \ 2\rbrack\ = \ 4$.

Rezolvare: $3x\ - \ 2\ \in \ \lbrack 4;\ 5)$ ⇒ $3x\ \in \ \lbrack 6;\ 7)$ ⇒ $x\ \in \ \lbrack 2;\ \frac{7}{3})$

NIVELUL III – Ecuații, proprietăți și discuții de caz

15. Rezolvați ecuația ${\lbrack x\rbrack}^{2}\ - \ 5\lbrack x\rbrack\ + \ 6\ = \ 0$.

Rezolvare: Notăm $n\ = \ \lbrack x\rbrack$: $n^{2}\ - \ 5n\ + \ 6\ = \ 0$ ⇒ $n\ = \ 2$ sau $n\ = \ 3$. Obținem $x\ \in \ \lbrack 2;\ 3)$ sau $x\ \in \ \lbrack 3;\ 4)$, adică $x\ \in \ \lbrack 2;\ 4)$.

16. Rezolvați ecuația ${\{ x\}}^{2}\ = \ \{ x\}$.

Rezolvare: ${\{ x\}}^{2}\ - \ \{ x\}\ = \ 0$ ⇒ $\{ x\}(\{ x\}\ - \ 1)\ = \ 0$. Cum $0\ \leq \ \{ x\}\ < \ 1$, soluția $\{ x\}\ = \ 1$ este imposibilă, rămâne $\{ x\}\ = \ 0$, deci $x\ \in \ {\mathbb{Z}}$.

17. Rezolvați ecuația $\lbrack x\rbrack\ + \ \{ x\}\ = \ 2x\ - \ 3,4$.

Rezolvare: Folosind identitatea $\lbrack x\rbrack\ + \ \{ x\}\ = \ x$, ecuația devine $x\ = \ 2x\ - \ 3,4$ ⇒ $x\ = \ 3,4$.

18. Rezolvați inecuația $2\ < \ \lbrack x\rbrack\ < \ 6$, $x\ \in \ {\mathbb{R}}$.

Rezolvare: Cum $\lbrack x\rbrack$ este număr întreg, $\lbrack x\rbrack\ \in \ \{ 3;\ 4;\ 5\}$, deci $x\ \in \ \lbrack 3;\ 6)$.

19. Determinați valorile posibile ale expresiei $E\ = \ \{ x\}\ + \ \{ - x\}$, $x\ \in \ {\mathbb{R}}$.

Rezolvare: Dacă $x\ \in \ {\mathbb{Z}}$, atunci $\{ x\}\ = \ \{ - x\}\ = \ 0$, deci $E\ = \ 0$. Dacă $x\ \in \ {\mathbb{R}}$ nu este întreg, scriem $x\ = \ \lbrack x\rbrack\ + \ f$ cu $f\ \in \ (0;\ 1)$; atunci $- x\ = \ ( - \lbrack x\rbrack - 1)\ + \ (1 - f)$ cu $1 - f\ \in \ (0;1)$, deci $\{ - x\}\ = \ 1 - f$ și $E\ = \ f\ + \ (1 - f)\ = \ 1$. Așadar $E\ \in \ \{ 0;\ 1\}$.

20. Arătați că $\lbrack x\ + \ 1\rbrack\ - \ \lbrack x\rbrack\ = \ 1$, oricare ar fi $x\ \in \ {\mathbb{R}}$.

Rezolvare: Cum 1 este întreg, $\lbrack x\ + \ 1\rbrack\ = \ \lbrack x\rbrack\ + \ 1$ (proprietatea de mai sus), deci $\lbrack x + 1\rbrack - \lbrack x\rbrack\ = \ 1$, pentru orice $x\ \in \ {\mathbb{R}}$.

21. Rezolvați ecuația $\lbrack x\rbrack\ \cdot \ \{ x\}\ = \ 0$.

Rezolvare: Un produs este 0 dacă unul din factori este 0. Dacă $\lbrack x\rbrack\ = \ 0$ atunci $x\ \in \ \lbrack 0;\ 1)$; dacă $\{ x\}\ = \ 0$ atunci $x\ \in \ {\mathbb{Z}}$. Soluția finală: $x\ \in \ \lbrack 0;\ 1)\ \cup \ {\mathbb{Z}}$.

NIVELUL IV – Performanță și tip concurs

22. Rezolvați ecuația $\lbrack x\rbrack\ + \ \lbrack 2x\rbrack\ = \ 10$, $x\ \in \ {\mathbb{R}}$.

Rezolvare: Notăm $n\ = \ \lbrack x\rbrack$, $x\ = \ n\ + \ f$, $f\ \in \ \lbrack 0;\ 1)$. Atunci $\lbrack 2x\rbrack\ = \ 2n\ + \ \lbrack 2f\rbrack$, unde $\lbrack 2f\rbrack\ = \ 0$ dacă $f\ < \ 0,5$ și $\lbrack 2f\rbrack\ = \ 1$ dacă $f\ \geq \ 0,5$. Ecuația devine $3n\ + \ \lbrack 2f\rbrack\ = \ 10$. Cazul $\lbrack 2f\rbrack\ = \ 0$ dă $3n\ = \ 10$ (imposibil, n nu ar fi întreg). Cazul $\lbrack 2f\rbrack\ = \ 1$ dă $3n\ = \ 9$ ⇒ $n\ = \ 3$, $f\ \in \ \lbrack 0,5;\ 1)$. Soluție: $x\ \in \ \lbrack 3,5;\ 4)$.

23. Demonstrați identitatea lui Hermite: $\lbrack x\rbrack\ + \ \lbrack x\ + \ \frac{1}{2}\rbrack\ = \ \lbrack 2x\rbrack$, pentru orice $x\ \in \ {\mathbb{R}}$.

Rezolvare: Fie $n\ = \ \lbrack x\rbrack$ și $f\ = \ \{ x\}\ \in \ \lbrack 0;\ 1)$, deci $x\ = \ n\ + \ f$. Distingem două cazuri. Dacă $f\ < \ \frac{1}{2}$: $x\ + \ \frac{1}{2}\ \in \ \lbrack n;\ n + 1)$ deci $\lbrack x\ + \ \frac{1}{2}\rbrack\ = \ n$; iar $2x\ = \ 2n\ + \ 2f$ cu $2f\ < \ 1$ deci $\lbrack 2x\rbrack\ = \ 2n$. Suma din stânga este $n\ + \ n\ = \ 2n\ = \ \lbrack 2x\rbrack$. Dacă $f\ \geq \ \frac{1}{2}$: $x\ + \ \frac{1}{2}\ \in \ \lbrack n + 1;\ n + 2)$ deci $\lbrack x + \frac{1}{2}\rbrack\ = \ n + 1$; iar $2f\ \in \ \lbrack 1;2)$ deci $\lbrack 2x\rbrack\ = \ 2n + 1$. Suma din stânga este $n\ + \ (n + 1)\ = \ 2n + 1\ = \ \lbrack 2x\rbrack$. În ambele cazuri identitatea este adevărată.

24. Rezolvați ecuația $\{ x\}\ + \ \{ 2x\}\ = \ 1$, $x\ \in \ \lbrack 0;\ 1)$.

Rezolvare: Pe $\lbrack 0;\ 1)$ avem $\{ x\}\ = \ x$. Dacă $x\ < \ 0,5$: $2x\ < \ 1$ deci $\{ 2x\}\ = \ 2x$, ecuația devine $3x\ = \ 1$ ⇒ $x\ = \ \frac{1}{3}$ (convine, < 0,5). Dacă $x\ \geq \ 0,5$: $2x\ \in \ \lbrack 1;2)$ deci $\{ 2x\}\ = \ 2x\ - \ 1$, ecuația devine $3x\ - \ 1\ = \ 1$ ⇒ $x\ = \ \frac{2}{3}$ (convine, ≥ 0,5). Soluții: $x\ \in \ \{\frac{1}{3};\ \frac{2}{3}\}$.

25. Determinați $x\ \in \ {\mathbb{R}}$ astfel încât ${\lbrack x\rbrack}^{2}\ = \ x\ + \ \lbrack x\rbrack$.

Rezolvare: Notăm $n\ = \ \lbrack x\rbrack$, $x\ = \ n\ + \ f$, $f\ \in \ \lbrack 0;\ 1)$. Ecuația devine $n^{2}\ = \ 2n\ + \ f$, deci $f\ = \ n^{2}\ - \ 2n$. Condiția $0\ \leq \ f\ < \ 1$ revine la $n^{2}\ - \ 2n\ \geq \ 0$ și $n^{2}\ - \ 2n\ - \ 1\ < \ 0$, adică $n\ \leq \ 0$ sau $n\ \geq \ 2$, și $n\ \in \ (1 - \sqrt{2};\ 1 + \sqrt{2})$ ≈ $( - 0,41;\ 2,41)$. Singurele întregi care satisfac ambele condiții sunt $n\ = \ 0$ și $n\ = \ 2$, ambele cu $f\ = \ 0$. Obținem soluțiile $x\ = \ 0$ și $x\ = \ 2$.
